# Your Move, Prime Minister

A playable, mobile-first prototype of a UK government strategy game.

## Play
This branch contains a static web app. Open `index.html` locally, or deploy the branch to any static host.

## Hosting
No build step is required.

- Publish directory: repository root
- Build command: none
- Entry file: `index.html`
